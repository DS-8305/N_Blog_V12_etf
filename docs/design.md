# ETF 포스팅 자동화 설계

사용자 지정 대상은 DS-8305/N_Blog_V12_etf main이다. 첨부 문서의 v12_etf 저장소 생성 지시보다 이 요청이 우선한다. 기존 대상은 공개 저장소이므로 공개 범위를 바꾸지 않으며 런타임 자료를 커밋하지 않는다.

입력은 ETF symbol, market, asOfDate. source-hints.json의 공급자 설정으로 검토된 공식/허가 데이터 JSON을 읽거나 허용된 HTTPS JSON 공급자에서 수집한다. 범용 공급자는 동일한 ETF 정체성 및 필드별 증빙을 요구한다. 자동 운용사 추측이나 비공식 무료 시세 대체는 하지 않는다. 데이터·캡처·생성 이미지가 미확인인 경우 needs_user로 중단한다.

팩트 검증 후 공식 상품 영역 캡처, AUM/비용·52주 시장가격·편입/노출 카드, 외부 AI 공급자 또는 검토된 생성 이미지로 5장 자산을 구성한다. 각 수치와 독립 기준일은 사실 ID에 연결된다. 공식 화면 캡처와 AI 이미지를 데이터 카드로 위장하지 않는다.

원고는 고정 5섹션, 7제목 후보, 짧은 한국어 존댓말과 상품별 위험 문구를 만든다. 저장 전 원고·출처·이미지 해시를 다시 검증한다. V10의 소유 탭, CDP/profile 잠금, 입력 체크포인트, 업로드 검증, 저장목록 재열람 로직을 ETF 계약에 이식한다. 복구 안내는 자동 해제하지 않는다. 저장 불확실 시 재저장이 아니라 확인만 수행한다.

실제 공급자 설정·네이버 로그인 없이 실시간 인수 테스트를 주장하지 않는다. 오프라인 수집/렌더/CLI 통합과 실제 브라우저의 모의 상품페이지 캡처를 별도 검증한다.
