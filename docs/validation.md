# 검증 범위와 운영 인수

| 범위 | 결과 | 증거/제약 |
|---|---|---|
| 단위/통합 테스트 | 수행 | pnpm test, 가상 자료로 계약·수집·카드·원고·CLI·저장 오류 검증 |
| 타입/배포 번들 | 수행 | pnpm typecheck, pnpm build, node dist/cli.js help |
| 브라우저 캡처 | 모의 페이지 및 SPYM 공식 페이지 수행 | headless fixture와 로그인된 전용 CDP의 실제 운용사 캡처를 별도로 확인 |
| AI 이미지 | SPYM 콘셉트 생성 수행 | 내장 image_gen 생성물을 reviewed_file로 연결; HTTP 이미지 공급자는 미실행 |
| 미국 ETF 실자료 | SPYM 수행 | 공식 원자료를 reviewed_json으로 준비하여 수집/렌더/원고 검증 |
| 국내/특수 ETF 실자료 | 미실행 | 실제 종목 및 공급자 설정 필요 |
| 실제 네이버 임시저장 재열람 | SPYM 수행 | 한 번 저장 후 고유 제목을 재열람하여 5장·본문·캡션·출처 일치 영수증 확인 |

M0~M7의 오프라인 계약과 공급자/임시저장 연결 코드가 구현되어 있습니다. M8은 SPYM 한 종목에서 운영자 개입을 포함해 확인했습니다. 자료 준비는 reviewed_json 경로를 사용하며 자동 종목 검색 어댑터는 제공하지 않습니다. 상세 절차와 개입 범위는 [SPYM 실제 테스트 기록](live-spym-test.md)에 있습니다.

운영 인수에서는 공식 ETF 하나를 선택해 symbol/market/ISIN/운용사/클래스를 상호 확인하세요. 출처·라이선스·비용 정의·52주 거래가격 기준·독립 편입일을 검토한 뒤 collect, render, draft:check를 실행합니다. 세 카드의 한글/긴 이름과 캡처 가림 여부를 직접 확인하고 AI 라벨을 확인합니다. 임시저장 후 목록 재열람과 receipts를 확인하며 각 단계 PASS/FAIL/미실행을 구분해 기록하세요.

## 구현 검증 기록 (2026-10-11)

55개 테스트: 계약 16, 수집 5, 카드/원고 9, CLI 3, 브라우저 캡처 1, 편집기 도움말/커서/링크카드 5, 임시저장 안전 3, 회귀 13. pnpm test/typecheck/build를 확인했습니다. SPYM 섹션 본문은 947자이며 이미지 5장을 시각 검수했습니다.

독립 읽기 전용 코드 리뷰 후 요청 기준일/마지막 거래일 분리, 보장 표현과 부정 고지 구분, offset이 다른 조회 시각 비교, 손상된 상태 파일의 잠금 해제, null 필수 수치 검증, 저장 불확실 상태 유지, 인버스 목표 방향을 회귀 테스트로 확인했습니다. SPYM 운영 검증에서 Last 시세, 첫 실행 도움말, 업로드 후 라이브러리, 긴 문단과 링크카드 처리를 보완했습니다. 상품·공급자별 원자료 검토와 다른 네이버 UI 버전은 추가 운영 인수 항목입니다.
