# 검증 범위와 운영 인수

| 범위 | 결과 | 증거/제약 |
|---|---|---|
| 단위/통합 테스트 | 수행 | pnpm test, 가상 자료로 계약·수집·카드·원고·CLI·저장 오류 검증 |
| 타입/배포 번들 | 수행 | pnpm typecheck, pnpm build, node dist/cli.js help |
| 브라우저 캡처 | 모의 상품페이지 | 실제 headless Chrome + 로컬 route fulfillment. 실제 운용사 페이지 검증과 다름 |
| AI 이미지 공급자 | 계약 및 실패 경로 | API 키·실제 공급자 없음. 생성 성공 미주장 |
| 국내/미국/특수 ETF 실수집 | 미실행 | 실제 종목·허가된 데이터 provider 설정 필요 |
| 실제 네이버 임시저장 재열람 | 미실행 | 사용자 로그인 CDP/profile 없음. draft_saved 인수 완료 미주장 |

M0~M5의 오프라인 계약/렌더와 M6~M7의 이미지 공급자/임시저장 연결 코드가 구현되어 있습니다. M8의 실제 운영 인수는 별도입니다. 설치만으로 ETF 시세가 자동 검색되는 제품으로 표현하지 않습니다.

운영 인수에서는 공식 ETF 하나를 선택해 symbol/market/ISIN/운용사/클래스를 상호 확인하세요. 출처·라이선스·비용 정의·52주 거래가격 기준·독립 편입일을 검토한 뒤 collect, render, draft:check를 실행합니다. 세 카드의 한글/긴 이름과 캡처 가림 여부를 직접 확인하고 AI 라벨을 확인합니다. 임시저장 후 목록 재열람과 receipts를 확인하며 각 단계 PASS/FAIL/미실행을 구분해 기록하세요.
