# ETF 수치 정의

| 필드 | 의미 | 검증 |
|---|---|---|
| AUM | ETF 순자산총액 | net_assets, 양수, 원통화·기준일. 기업 시총 금지 |
| 비용 | total_fee / total_expense / synthetic_total_fee / expense_ratio | 총보수 / 총보수·비용 / 합성총보수 / Expense ratio 명칭 일치, 연율, 각 기준일 |
| quote | ETF 1주당 거래소 시장가격 | market, close/intraday, 가격보정 방식, 거래소 시간대·관측 시각 |
| range52w | 52주 시장가격 범위 | 350~370일 기간, 고가>저가, 관측 시세 포함, 통화·가격 기준·마감일 동일 |
| nav | 순자산 단위당 기준가, 선택 자료 | nav로 별도 기록; 52주 카드에 혼합 금지 |
| exposures | ETF 실제 편입 / 벤치마크 구성 | 두 기준 혼합 금지; full일 때만 100% 근사 검증 |

보유자료 기준일은 가격 기준일과 별개입니다. 오래된 편입자료에는 경고를 기록하며 실제 공개일을 카드와 원고에 남깁니다. 상위 공개 종목만으로 전체 구성 검증을 주장하지 않습니다. 기타 / 미표시는 상위 항목을 제외한 비중이며, 실보유를 확인한 특정 자산 이름이 아닙니다.

USD AUM과 KRW 거래가격이 공식 자료에 각각 존재할 수 있습니다. AUM 원통화를 그대로 보존하고, 거래가격과 52주 범위의 통화만 같은지 검증합니다. 별도 환율 없이 환산하지 않습니다. 가격 범위는 분배금 재투자 총수익률이 아닙니다.

레버리지·인버스 목표배수와 환헤지·선물·합성·커버드콜 features는 공식 문서로 확인한 값만 입력합니다. 상품 특성에 맞는 위험을 다섯 번째 섹션에 표시하며 분배금 지급·금액을 보장하지 않습니다.
